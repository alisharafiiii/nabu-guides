LangGraph makes an agent stop.

It maps the steps around an AI agent, remembers where it is, pauses for a human, then resumes reliably.

LangGraph is a low-level orchestration runtime for long-running, stateful agent workflows. LangChain gives an agent models and tools; LangGraph controls the route between them.

Why it matters

A real workflow can branch, fail halfway, need approval, or run for hours. LangGraph gives it explicit state, nodes, edges, checkpoints and interrupts.

Important: LangGraph controls when a workflow continues. It is not the trust anchor. For sensitive actions, the hardware device still decodes and enforces the final policy.

The jargon, translated

State

The shared notebook: messages, tool results and approval status.

Node + edge

A node does one job; an edge chooses what happens next.

Checkpoint

A saved snapshot, so a workflow can resume after a failure.

Interrupt

A deliberate stop until a human or approved system responds.

Real-life examples

Customer refund

Under $30 and in policy? Continue. Above that? Pause and route to a human.

Research agent

Search, read and draft. If a claim is high stakes, send it to a reviewer before publishing.

Onchain action

The agent proposes a swap. LangGraph pauses outside scope; hardware then checks the decoded transaction, limits and allowlists before it can sign.

Smallest useful pattern

START → agent → tool → risky action? | no: continue | yes: interrupt → human → hardware-enforced execution

Use it when the path matters: multiple steps, persistence, approvals or recovery. Skip it for a one-call app.
